# 검증 기록

검증 환경: macOS, Unity 6000.3.10f1, 2026-09-21.

## 완료한 검증

- Unity 스크립트 컴파일 오류 없음.
- 4개 counterbalancing 그룹의 144개 요인 조합 중복·누락 검사, 동일 시드 재현성.
- 12회 연습 스케줄, 전후방·높이·거리 경계, 4채널 매핑과 출력 범위 검사.
- Play Mode에서 144회 전체 상태 전이와 정답 응답, CSV 144행 및 필드 정합성 확인.
- 잘못된 전후·높이·거리 응답, 시간초과, 중단, 재청취 횟수와 진동 중지 검사.
- EventSystem 1개 확인.
- 실제 Unity UI에서 연습 시작 버튼 → Space로 드론 선택 → 거리 버튼 → 응답 기록 화면 확인.
- 다른 게임 창 비율에서 메뉴가 잘리지 않도록 CanvasScaler 설정 수정 후 시각 확인.
- CSV 분석 도구를 합성 세션 기록에 실행하여 조건별 집계 확인.

자동 검증은 정답 위치를 코드가 알고 응답한 기능 검사입니다. 정확도 수치를 연구 결과로 사용할 수 없습니다. 스크립트는 `LabVerification.Run()`으로 재실행할 수 있습니다.

## 검증하지 않은 범위

실제 헤드폰 청감·HRTF 정확도, 실제 진동 장치, UDP 수신 브리지, 출력 지연, 지각적 강도 등가성, 참가자 불편함, Windows/Linux 실행은 검증하지 않았습니다. 장치 ACK가 없으므로 UDP 전송 성공을 장치 작동으로 취급하지 않습니다.
