# 빠른 시작 — Player 자동 연결 + FPS 미션

1. 압축을 전부 풀고 **GCCD.exe**를 실행합니다. `GCCD_Data`와 DLL을 함께 옮깁니다.
2. bHaptics Player를 켜고 조끼를 연결합니다. 시작 화면이 약 2초 간격으로 자동 확인합니다.
3. **짧게 진동 보내기**로 모터 한 개에 20%, 0.2초 요청을 보냅니다. 실제로 느꼈을 때만 확인 버튼을 누릅니다.
4. **FPS 미션 시작**을 누릅니다. WASD 이동, 마우스 조준·왼쪽 클릭 사격, 보급품 근처에서 E 수집, ESC 일시정지입니다.
5. 보급품 3개와 표적 5개가 목표입니다. 진행 중 8초 이후 및 보급품 수집 직후 예고 없이 화면 밖 위협의 진동을 요청합니다. 조끼가 없으면 화면 체험으로 실행합니다.

이 실행 패키지는 **Player 로컬 연결**을 사용합니다. 다른 노트북에서도 Developer Window/App ID/API Key를 입력할 필요가 없습니다. 해당 노트북의 Player에서 조끼를 연결해야 합니다. 이 통신 경로를 지원하지 않는 Player 버전이나 로컬 포트 접근 문제는 연결 대기 상태로 표시됩니다. 이번 Mac에서는 연결된 조끼 1대 조회와 요청 전송을 확인했습니다. Windows 실제 실행과 착용 체감은 별도 확인이 필요합니다.

## 화면 구성

첫 화면은 조끼 연결 / 짧은 진동 확인 / FPS 미션·화면 연습입니다. 장비 이름은 자동으로 찾으며, SDK 초기화 객체 중복을 방지합니다. 연구용 교정, 실험 B, 데이터 검토와 자세한 설정은 **고급 설정**에 있습니다. 저장한 연구 설정은 다음 실행 때 자동으로 불러옵니다.

FPS 미션은 **MISSION_DEMO** 자료입니다. 위치별 매핑이 교정되지 않은 가상 프로필일 수 있으므로 실제 방향 정확도를 보장하지 않으며 실험 A/B 본 측정에 포함하지 않습니다. 원래 실험 A의 카메라·자극·채점 조건은 유지됩니다. 연구 설정의 검증 완료 상태를 자동으로 만들어 채우지 않습니다.

## 출력 경로

공식 구형 bHaptics PlayerRequest WebSocket 프로토콜을 참고하여 `ws://127.0.0.1:15881/v2/feedbacks`에 연결합니다. 40채널 합성 배열을 전면 20/후면 20 프레임으로 나누어 **같은 WebSocket 메시지**에 제출합니다. 위협마다 Stop을 호출하지 않으며, 중지는 이 앱이 만든 키만 대상으로 합니다. 전면/후면 배열 인덱스의 실제 신체 위치·물리 동시성은 별도 교정해야 합니다. 본 실험에서는 `local-player-v1` 출력 경로에 대한 검증 근거가 필요합니다.

Player가 요청을 받았다는 것과 실제 피부 진동은 구분합니다. 상태 `PLAYER_REQUEST_SENT_PHYSICAL_UNCONFIRMED`는 물리 확인 완료가 아닙니다. 외부 서버나 새 페어링 프로그램을 추가하지 않습니다.

참고: https://github.com/bhaptics/haptic-library/wiki/Documentation 및 해당 저장소의 include/shared/model.h, samples/csharp/src/Bhaptics.Tact/WebSocketSender.cs.
