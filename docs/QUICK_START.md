# 빠른 시작 — OUTPOST 07

1. 압축을 **전부** 풉니다. `GCCD.exe`, `GCCD_Data`, DLL은 같은 폴더에 둡니다.
2. bHaptics Player에서 조끼를 연결합니다. 이 게임에서 Developer Window 로그인이나 App ID/API Key 입력은 필요하지 않습니다.
3. `GCCD.exe`를 실행합니다. 로비에 **조끼 연결됨**이 표시되면 **짧은 진동 확인**을 누릅니다. 한 모터에 20%, 0.2초를 요청합니다. 직접 느꼈을 때만 **진동이 느껴졌어요**를 누릅니다.
4. **작전 시작**을 누릅니다. 조끼 없이도 화면 체험이 가능합니다. `미션 바로 시작.bat`는 로비를 건너뜁니다.
5. 녹색 거리 표시를 따라 보급품 3개를 회수하고 경계 드론을 5대 이상 무력화하면 완료됩니다. 적 위치는 매번 바뀝니다. 시작 8초 후부터, 그리고 보급품 회수 후 시야 밖 위협에 대한 진동을 요청합니다.

| 조작 | 기능 |
|---|---|
| WASD / 마우스 | 이동 / 시선 회전 |
| 마우스 우클릭 유지 | 가늠쇠 조준, 시야 확대 |
| 마우스 좌클릭 유지 | 사격·연사 |
| R | 30발 탄창 재장전 |
| Shift | 달리기 |
| E | 3m 이내 보급품 회수 |
| ESC | 일시정지 / 계속 |

창 밖으로 전환하면 자동으로 일시정지합니다. **작전 계속**으로 복귀합니다. 소리가 작으면 운영체제의 출력 장치와 볼륨을 확인하세요.

## 다른 노트북에서

Unity와 Developer Window 없이 전체 실행 폴더와 해당 노트북의 bHaptics Player만 사용합니다. Player에서 먼저 조끼가 연결되어야 합니다. 로컬 포트 연결을 지원하지 않는 Player 버전이나 접근 실패는 연결 대기로 표시됩니다. 장비를 연결한 뒤 약 2초 동안 기다리세요. 이 Mac에서 Player가 연결된 조끼 1대를 보고하는 것을 확인했습니다. Windows 실행과 실제 착용 감각은 아직 확인하지 않았습니다.

## 연구자용

로비의 **연구자 설정**에서 교정, 실험 A/B, 데이터 검토를 엽니다. 미션은 **MISSION_DEMO**로 별도 저장하며 A/B 본 측정 자료에 포함하지 않습니다. 가상 매핑의 실제 방향 정확도와 물리 동시성은 별도 교정해야 합니다. 연구 설정의 검증 완료 상태를 자동으로 채우지 않습니다.

기본 출력은 공식 구형 [PlayerRequest 프로토콜](https://github.com/bhaptics/haptic-library/wiki/Documentation)의 `ws://127.0.0.1:15881/v2/feedbacks` 경로입니다. 40채널 합성 배열을 전면 20/후면 20 프레임으로 나누어 **같은 메시지**에 제출합니다. 중지는 이 앱이 만든 키만 대상으로 합니다. Player 요청 전송은 피부 진동 확인과 구분합니다. `PLAYER_REQUEST_SENT_PHYSICAL_UNCONFIRMED`는 물리 확인 완료가 아닙니다.

미션 시드와 첫 적 배치는 `ExperimentData/MISSION_DEMO/<실행 ID>/layout.json`에 저장합니다. 무료 에셋의 저작자·라이선스는 [FREE_ASSETS.md](FREE_ASSETS.md)에 있습니다.
