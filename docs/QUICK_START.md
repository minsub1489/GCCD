# 빠른 시작 — Finding Threat

1. 압축을 **전부** 풉니다. `GCCD.exe`, `GCCD_Data`, DLL은 같은 폴더에 둡니다.
2. bHaptics Player에서 조끼를 연결합니다. 이 게임에서 Developer Window 로그인이나 App ID/API Key 입력은 필요하지 않습니다.
3. `GCCD.exe`를 실행합니다. 로비에 **조끼 연결됨**이 표시되면 **진동 · 방향/거리 확인**을 누릅니다. 앞·오른쪽·뒤·왼쪽을 하나씩 눌러 0.2초 진동을 확인하고, 해당 방향에서 느꼈을 때만 확인 버튼을 누릅니다. 방향이 반대라면 펼침 메뉴에서 좌우/앞뒤를 보정합니다. **거리 · 세기** 탭에서 **36m 약함 → 21m 중간 → 6m 강함**을 비교합니다. 세 단계는 같은 앞 방향·같은 0.2초이며, 느꼈을 때만 확인 버튼을 누릅니다.
4. **작전 시작**을 누릅니다. 조끼 없이도 화면 체험이 가능합니다. `미션 바로 시작.bat`는 로비를 건너뜁니다.
5. A동의 실내 주 복도에서 시작합니다. 양쪽 건물의 작업실·창고 16개와 복도가 연결되어 있습니다. 지도에서 보급품 위치를 확인하고, 보급품 3개를 회수하면서 경계 드론을 5대 이상 무력화하세요.
6. 위협 진동을 요청하면 게임이 멈추고 위치 응답 지도가 열립니다. **느낀 위치를 클릭 → 표시 완료 · 게임 계속** 순서로 진행합니다. 실제 위협 위치와 개수는 보여주지 않습니다. 기억나지 않으면 비워 두고 완료할 수 있습니다. 조끼 없이 실행하면 같은 흐름을 화면으로 체험합니다.

| 조작 | 기능 |
|---|---|
| WASD / 마우스 | 이동 / 시선 회전 |
| 마우스 우클릭 유지 | 가늠쇠 조준, 시야 확대 |
| 마우스 좌클릭 유지 | 사격·연사 |
| R | 30발 탄창 재장전 |
| Shift | 달리기 |
| Space | 점프 |
| C | 앉기 / 서기 전환. 머리 위 공간이 부족하면 앉은 상태 유지 |
| Tab | 미니맵 켜기 / 끄기. 지도에는 내 위치·방향·보급품 표시 |
| E | 3m 이내 보급품 회수 |
| ESC | 일시정지 / 계속 |

미니맵의 위쪽은 북쪽입니다. 주황색 낮은 통로는 앉아서 지나갑니다. 실내 출입구와 복도를 통해 건물 안팎으로 이동할 수 있습니다.

응답 지도에서 같은 표시를 누르면 삭제하며 **마지막 표시 취소 / 모두 지우기**도 사용할 수 있습니다. 표시할 개수나 정답 점은 제시하지 않습니다. 응답 중에는 ESC나 Tab으로 응답을 건너뛰거나 이동·사격할 수 없으며, 제출하면 멈춘 시점부터 이어집니다. 출력 실패와 조끼 없는 체험은 응답 화면에서 구분합니다.

창 밖으로 전환하면 자동으로 일시정지합니다. **작전 계속**으로 복귀합니다. 소리가 작으면 운영체제의 출력 장치와 볼륨을 확인하세요.

## 다른 노트북에서

Unity와 Developer Window 없이 전체 실행 폴더와 해당 노트북의 bHaptics Player만 사용합니다. Player에서 먼저 조끼가 연결되어야 합니다. 로컬 포트 연결을 지원하지 않는 Player 버전이나 접근 실패는 연결 대기로 표시됩니다. 장비를 연결한 뒤 약 2초 동안 기다리세요. 이 Mac에서 Player가 연결된 조끼 1대를 보고하는 것을 확인했습니다. Windows 실행과 실제 착용 감각은 아직 확인하지 않았습니다.

## 연구자용

메인에서 참가자 ID를 입력하고 **실험 시작**을 누릅니다. 기본은 **화면 연습**이며, 미확정 위협 수는 연습에서만 6개를 사용합니다. F9의 **설정 저장**으로 설정 파일을 만들 수 있습니다. 실제 측정은 파일의 `TotalThreatCount`(2 이상), `TrialsPerCondition` 및 `LobbyMode`(`PILOT` 또는 `MAIN`)를 지정하고 장비·파일럿 검증을 완료해야 합니다. 연구 모드는 정면을 포함한 360°를 사용하며, 각도 θ의 절반을 좌우에 적용합니다. F9에서 교정·자극 검증·데이터 검토를 엽니다. 미션은 **MISSION_DEMO**로 별도 저장합니다.

기본 출력은 공식 구형 [PlayerRequest 프로토콜](https://github.com/bhaptics/haptic-library/wiki/Documentation)의 `ws://127.0.0.1:15881/v2/feedbacks` 경로입니다. 40채널 합성 배열을 전면 20/후면 20 프레임으로 나누어 **같은 메시지**에 제출합니다. 중지는 이 앱이 만든 키만 대상으로 합니다. Player 요청 전송은 피부 진동 확인과 구분합니다. `PLAYER_REQUEST_SENT_PHYSICAL_UNCONFIRMED`는 물리 확인 완료가 아닙니다.

위협 이벤트의 당시 위치·시선, 출력 요청 결과, 표시 좌표와 응답 시간·완료/중도 종료 상태도 MISSION_DEMO에 저장합니다. 이 자료는 연구 실험와 분리합니다.

미션 시드와 첫 적 배치는 `ExperimentData/MISSION_DEMO/<실행 ID>/layout.json`에 저장합니다. 무료 에셋의 저작자·라이선스는 [FREE_ASSETS.md](FREE_ASSETS.md)에 있습니다.


## 완료 결과와 CSV

미션 결과에서 이벤트를 골라 실제 위협과 표시 위치를 비교합니다. 방향 허용각 미만인 응답은 유지 위협과 한 개씩 연결하며, 위협과 응답이 같은 옆구리 구간(좌우 정측면 기준 ±22.5°)에 있어도 방향이 맞은 것으로 인정합니다. 정답마다 기본 1점에 위치 보너스를 더합니다. 보너스는 `1 / (1 + 수평 위치 오차 / 기준 거리)`점입니다. 예를 들어 기준이 3m면 오차 0m는 1점, 3m는 0.5점, 6m는 약 0.33점의 보너스를 받습니다. 다른 유지 위협까지 비교해도 정답에 연결되지 않은 표시는 0점입니다.

메인에서 **CSV 저장 폴더 열기**를 누르면 최근 FPS 결과의 `csv` 폴더를 바로 엽니다. 결과 화면에서는 현재 실행의 폴더를 열 수 있습니다. 경로는 화면에 표시하며 선택·복사할 수 있습니다. 저장 실패 때는 **CSV 다시 저장**으로 재시도합니다. 실행별 폴더를 만들어 이전 결과를 보존합니다.

- `summary.csv`: 전체 및 출력 종류별 종합 정확도·누락·오차·미션 기록
- `events.csv`: 이벤트별 정확도, 표시 수, 출력 상태와 매핑·세기 인코딩 버전/범위
- `positions.csv`: 실제/표시 좌표와 1대1 대응, 오차 상세

UTF-8 BOM 형식으로 Excel에서 열 수 있습니다. 화면 체험과 조끼 요청은 구분하며, 출력 실패·중단·중도 종료 응답은 정확도 집계에서 제외합니다. 조끼 요청 기록은 실제 착용 감각을 확인했다는 의미가 아닙니다. CSV는 원본 이벤트 JSON에서 다시 생성합니다. 미션을 중간에 종료해도 해당 시점까지 CSV로 정리하며 상태는 `aborted`입니다.

기본 저장 위치(실제 전체 경로는 결과 화면 표시):

- Windows: `%USERPROFILE%\AppData\LocalLow\GCCD\Distance Priority Haptic Study\ExperimentData\MISSION_DEMO\<실행ID>\csv`
- macOS: `~/Library/Application Support/GCCD/Distance Priority Haptic Study/ExperimentData/MISSION_DEMO/<실행ID>/csv` (기존 Unity 데이터 폴더에 따라 다를 수 있음)

## 미션 진동 강도

위협 하나는 X40 모터 한 개를 울립니다. 방향에 따라 열을 선택하고, 높이가 비슷한 위협은 가운데 행을 사용합니다. 기본 모터 요청값은 6m에서 **80**, 21m에서 **50**, 36m에서 **20**입니다. 6~36m 사이에서 세기가 연속적으로 변하며, 여러 위협이 같은 모터에 배정되면 가장 강한 요청을 사용합니다. 시작 전 검사에도 같은 매핑과 거리 세기를 적용합니다. **진동 · 방향/거리 확인 → 거리 · 세기**에서 1~100 사이의 값을 입력하고 **세기 적용**을 누르면 FPS 작전에 반영됩니다. 가까움 ≥ 중간 ≥ 멀리 순서이며 같은 값도 입력할 수 있습니다. 적용값은 앱을 닫기 전까지 사용하며, 시행별 값은 events.csv에 기록합니다.

## 메인 실험 선택과 채점

메인에서 억제각 하나 또는 전체 각도와 최소·최대 위협 수를 직접 입력하고 **실험 시작**을 누릅니다. 세 항목을 모두 지정해야 실험을 시작합니다. 범위의 양 끝을 포함해 시행별 위협 수를 시드로 정합니다. 전체 각도에서는 같은 배치와 위협 수를 각 조건에서 재사용합니다.

방향 오차가 허용오차 미만이고 거리 범주가 같은 응답을 실제 위협과 일대일로 연결합니다. 방향이 정확히 일치하는 응답도 허용합니다. 어느 실제 위협 방향에도 가깝지 않은 표시는 한 개당 공동 정답 수에서 1을 감점합니다. 보정 점수는 max(0, 공동 정답 수 − 멀리 빗나간 표시 수) / 실제 위협 수입니다. 가까운 중복 표시는 감점하지 않습니다. 종료 화면에서 **CSV 저장**을 선택하면 CSV가 생성됩니다. **저장 없이 메인으로**를 선택하면 재개용 원본 기록만 남습니다. 종료 화면과 trials.csv에서 원점수와 보정 점수를 비교하고, responses.csv에서 방향 오차와 개별 감점 여부를 확인합니다.

종료 화면의 **이전 시행 / 다음 시행**으로 실제 위협을 확인합니다. 원형 지도와 목록에서 ●는 유지, 큰 주황색 ×는 억제를 뜻합니다. **유지 위협도 표시**를 끄면 억제 위협만 볼 수 있습니다. 억제된 위협의 방향·거리와 억제 기준 위협 ID도 표시됩니다.

FPS에서 **Tab**을 누르면 미니맵과 버튼이 열리며 작전이 잠시 멈춥니다. **실험 종료**는 현재까지의 결과를 열고, **로비로 돌아가기**는 바로 로비로 이동합니다. Tab을 다시 누르면 계속합니다. FPS는 로비에서 선택한 억제각을 적용합니다. **전체 각도**를 선택한 상태에서 작전을 시작하면 FPS에서는 45°를 씁니다. 결과 지도에서 주황 ×는 실제 좌표에 표시한 억제 위협입니다.

결과 화면은 억제가 있었던 첫 이벤트를 자동으로 엽니다. 이벤트 버튼에 억제 수가 표시됩니다. 억제 수가 0개이면 지도에 주황 ×가 나타나지 않습니다.

결과 지도에서 **억제각 보기**를 켜면 당시 내 위치를 중심으로 유지 위협 방향 양쪽의 억제 범위가 표시됩니다. 예를 들어 60°는 좌우 ±30°입니다. 0°에서는 적용 범위가 없습니다.

FPS 작전도 로비의 최소·최대 위협 수를 사용합니다. FPS에서는 2~12개를 지정할 수 있습니다. 동시 이벤트마다 범위 안에서 전체 개수를 뽑고, 억제되지 않은 위협만 한 번에 진동으로 요청합니다. 결과의 전체 수는 유지 수와 억제 수의 합입니다.

메인 위쪽의 **플레이어 이름**에서 한글·영문·숫자·밑줄·하이픈을 공백 없이 입력할 수 있습니다. **실험 시작 · 화면 연습** 중에는 화면 오른쪽 위 **로비로 돌아가기**로 나옵니다. 진행 중이던 시행은 중단으로 남습니다.

FPS 위치 응답은 로비에 입력한 **최대 위협 수**까지만 표시할 수 있습니다. 기존 표시를 삭제하면 다시 찍을 수 있으며 현재 표시 수와 한도는 응답 화면에 표시됩니다.

메인에서 **FPS 방향 허용각 (°)**과 **FPS 위치 보너스 기준 (m)**를 설정한 뒤 작전을 시작합니다. 설정값은 결과 화면과 CSV에서 확인할 수 있습니다.

FPS 결과 지도의 **오답 보기**는 오답으로 분류된 응답에 빨간 고리, **중복 보기**는 정답으로 연결되지 않았지만 이미 맞힌 위협과 방향이 가까운 응답에 하늘색 고리를 그립니다. 억제 위협은 실제 위치에 표시해도 정답으로 세지 않습니다. 이미 맞힌 위협 근처에 표시해도 다른 유지 위협과 방향이 맞으면 정답과 위치 보너스를 받습니다. 어느 정답에도 연결되지 않으면 오답으로 채점하며, 중복 고리는 가까운 표시를 확인할 때 사용합니다. 지도에 표시되는 연결선은 정답 쌍을 뜻합니다. 두 토글은 따로 켜고 끌 수 있습니다. 결과에는 오답 수와 획득 점수가 각각 표시됩니다.

FPS의 억제율 반영 점수는 **(획득 점수 ÷ 유지 위협 만점) × (1 − 0.5 × 억제율)**입니다. 위치 점수는 획득 점수를 전체 위협 만점으로 나눕니다. 유지 위협 인지율은 방향 정답 수로 따로 표시합니다.
