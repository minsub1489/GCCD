# 실내 확장과 위협 위치 응답 검증

검증일: 2026-11-02. Unity 6000.3.24f1, macOS. 기존 프로젝트와 별도인 검증 사본에서 테스트·Windows/macOS Release 빌드를 수행했다. 사용자 ProjectSettings, SDK 자격증명과 기존 연구 자료는 보존한다.

## 변경 내용

두 건물에 작업실·창고 16개, 주 복도, 여러 출입구·내부 문·우회 동선·낮은 연결 통로를 구성했다. 기존 CC0 소품과 새 CC0 바닥/벽 질감을 사용한다. 실제 벽의 설계와 두 지도는 MissionFloorPlan을 공유한다. Space 점프, C 앉기/서기, 머리 위 공간 검사와 Tab 미니맵을 추가했다.

위협 출력 요청 때 즉시 게임 진행을 멈추고 0.2초 펄스가 자연스럽게 끝나도록 한다. 일반 일시정지와 달리 응답 화면을 여는 행위 자체로 펄스를 취소하지 않는다. 포커스 상실·명시적 중지·종료는 출력을 중지한다. 응답 중 이동·사격·회수·재장전·조준·Tab/ESC 우회가 차단된다. 게임 시계도 멈춰 재장전과 다음 이벤트가 응답 시간만큼 건너뛰지 않는다. 제출 후 다음 이벤트를 새 간격으로 예약한다.

실제 위협 수는 가변이며 UI는 정답 위치·개수·고정 응답 슬롯을 표시하지 않는다. 일반 미니맵에도 적을 표시하지 않는다. 응답 지도에는 진동 당시 위치·방향과 사용자가 찍은 점만 표시한다. 새 위협의 실제 드론은 응답 종료 후 배치하여 화면으로 개수가 새지 않도록 한다. 빈 응답도 허용한다.

이벤트 JSON에는 원 위치, 당시 관찰자 위치·시선, 출력 receipt, 응답 좌표·실제 경과 시간, completed/aborted 상태를 기록한다. 초기 이벤트도 먼저 저장한다. 저장 실패 때는 응답을 유지하고 오류와 재시도 안내를 표시한다. 모든 자료는 MISSION_DEMO/not_research_data이며 연구 A/B 자극·채점·승인 조건은 변경하지 않는다.

## 실행한 검증

- C# 핵심 검사 **75 passed, 0 failed**. 지도 변환 왕복, 문/벽 구분, 모든 방의 연결성, 앉기 통로, 안전한 실내 생성, 정지 시계, 빈 응답·추가/삭제·취소·범위 검증 포함.
- Python 분석기 unittest **5 passed**.
- Unity **DTS_MISSION_PROBE_PASS**: 실제 출입구 통과, 점프 높이·착지, 앉기 캡슐·천장 아래 서기 차단, Tab 지도, 조준·오디오, 회수·명중·재장전, 응답 중 게임/시계 정지, 새 드론 숨김, 지도 선택/취소, 실제 UI 버튼 이벤트 제출·재개, 빈 응답·종료 복구 검사.
- Unity 연구 플랫폼 **DTS_SOFTWARE_VALIDATION_PASS**.
- Windows x64 및 macOS Release 빌드 성공.
- Mac 네이티브 실행에서 실내 화면, 개수/정답을 보여주지 않는 응답 지도·현재 위치·사용자 표시를 육안 확인.

새 핵심 검사 미구현 상태의 실패 후 구현했다. Unity 검사에서는 사격 광선이 플레이어 자신의 충돌체에 걸리는 실패를 확인하여 자기 레이어를 제외하도록 수정했고 같은 명중 검사로 재확인했다. 반복 검사 중 Unity Editor Search의 내부 IndexOutOfRangeException이 기록된 실행이 있지만 게임 컴파일·검사·빌드는 통과했다. 커버리지 비율은 측정하지 않았다.

## 검증 범위의 한계

Windows PC 실제 실행, 착용 진동의 체감·방향 매핑·물리 동시성, 실제 출력 장치의 총소리 청취, 장시간 성능과 다양한 화면 비율은 확인하지 않았다. 이번 위치 응답 검사는 시뮬레이션으로 수행했다. 실제 참가자나 파일럿 결과를 생성하지 않았다.
