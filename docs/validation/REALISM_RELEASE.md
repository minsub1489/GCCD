# OUTPOST 07 실사 질감 미션 검증

검증일: 2026-11-02. Unity 6000.3.24f1, macOS 로컬 환경. 실제 프로젝트의 별도 사본에서 테스트·빌드했으며 기존 ProjectSettings와 SDK 자격증명은 변경하지 않았다. 배포용 사본의 SDK App ID/API Key는 비웠고 기본 연결은 Player 로컬 경로다.

## 구현과 범위

- Poly Haven 2K PBR 텍스처·스캔 모델·HDRI, CC0 AKM, 발사·재장전 WAV 포함.
- 우클릭 조준/FOV 전환, 좌클릭 연사, 30발 탄창, 재장전 동안 발사 차단.
- 5대의 무작위 경계 드론, 보급품 3개, 시야 밖의 무작위 위협 3개. 위치 시드 기록.
- UI Toolkit 로비·HUD·목표 거리 마커·일시정지·완료 화면. OS 한국어 폰트 사용.
- 미션 로그는 MISSION_DEMO로 분리. 연구 A/B의 자극·정책·채점 로직은 변경하지 않음.

미션 검사는 패널에 연결된 실제 UI Toolkit 시작 버튼으로 NavigationSubmitEvent를 전달해 미션을 연다. 100개 이상의 환경 MeshRenderer, 오디오 리소스, 초기 5대, 조준 FOV, 보급품 회수 3개, raycast 명중 5회, 발사 간격·탄수, 재장전 차단/완료, 화면 밖 위협 3개, 시뮬레이션 출력, 종료 후 복구를 검사한다. 버튼 이벤트 검증은 마우스로 전체 사용자 여정을 끝까지 조작한 검사와 구분한다.

무작위 생성에 대해 동일 시드 재현·다른 시드 변화·장애물 회피·최소 간격·화면 밖 조건·생성 불가능 시 제한된 실패를 테스트했다. 새 생성기 없는 상태의 실패를 먼저 확인한 뒤 구현했다. 카메라/조명 복구 검사도 기존 구현에서 실패한 뒤 수정 후 통과했다. 미션 종료 때 시야·far clip·HDR/MSAA·안개·환경광·스카이·원래 조명을 복구한다.

## 확인하지 않은 사항

Windows PC에서 직접 실행하지 않았다. 착용자가 느끼는 진동, 모터 방향 매핑·물리 동시성, 실제 출력 장치에서의 총소리 청취, 장시간 성능 수치와 다양한 화면 비율은 확인하지 않았다. Player의 연결 보고·요청 접수와 실제 진동을 구분한다. 연구 파일럿이나 참가자 결과는 생성하지 않았다.

자동 검사 중 Unity Editor Search 인덱스의 내부 IndexOutOfRangeException이 기록된 실행이 있었으나 게임 스크립트 컴파일 오류 없이 실행 검사·빌드는 통과했다. 코드 커버리지 비율은 측정하지 않았다.

최종 확인 시 Player 자체 화면은 **TactSuit X40 연결 끊김**을 표시했고 게임도 연결 대기로 표시했다. 이전 연결 조회 확인과 현재 연결 상태를 구분한다. 배포 폴더 전체에서 원본 SDK 자격증명 값이 발견되지 않았음을 검사했다.
