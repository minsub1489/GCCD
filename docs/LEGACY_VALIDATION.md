# 검증 기록

- Unity 6000.3.24f1에서 Editor 연결 및 C# 컴파일 오류 없음 확인.
- SDK2 2.8.1을 설치하고 `GCCD_BHAPTICS_SDK2` 활성 상태의 실제 API 참조 컴파일 통과.
- 앞/뒤/좌/우, 45°/135° 경계, 변경된 Inspector 영역 각도 검증 통과.
- viewport 네 경계, 카메라 뒤, far clip 외부 판정 검증 통과.
- Play Mode에서 4방향 Threat 생성, 화면 안의 Front에서 요청 없음, Right/Back/Left에서 요청 발생 확인.
- 동일 상태 재평가 시 중복 요청 억제, 뒤를 돌아 Threat 획득 시 출력 정지, Threat 제거 시 상태 초기화 통과.
- 6000.3.24f1 Play Mode 통합 재검증에서도 동일 항목을 모두 통과했습니다. 통합 검증에서는 안정화 시간/요청 간격을 일시적으로 0으로 설정했으며, 종료 후 Scene의 기본값(0.1초/0.5초)은 유지됩니다. 따라서 실제 시간 간격이나 반응시간 정밀도를 검증한 결과는 아닙니다.
- macOS Development Build 결과: Succeeded. errors=1은 빌드 중 CLI 상태 조회의 main-thread timeout이며 C# 또는 플레이어 빌드 오류가 아닙니다. warnings=346은 기존 AI inference 셰이더와 Pipeline의 런타임 설정 관련 경고입니다. 패키지를 임의로 제거하지 않았습니다.
- macOS 앱의 실제 키보드/마우스 조작 및 X40 출력은 별도 확인이 필요합니다. 빌드 성공과 실제 장치 검증을 구분합니다.
- Scene/Prefab/Material의 GUID 참조가 프로젝트 및 URP 패키지에서 해석되는 것을 확인했습니다.

실제 X40 네 방향 진동은 아직 검증하지 못했습니다. SDK 설정에는 이벤트가 0개이며 배포 버전은 -1입니다. 물리 장치가 bHaptics Player에 연결되어 있다는 것과 Unity에서 올바른 패턴이 출력된다는 것은 별개의 검증입니다.

자동 실험이나 데이터 수집을 위한 검증이 아닙니다. 현재 화면 판정은 중심점 기준이며 가림 판정, 여러 위협의 우선순위, 거리 인코딩을 포함하지 않습니다.
