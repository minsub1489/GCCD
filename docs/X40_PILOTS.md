# X40 교정·식별·난이도 파일럿

2026-10-14: SDK2는 이 로컬 프로젝트에 설치·활성화했습니다. 현재 장비를 사용할 수 없으므로 실물 출력 성공, 체감 교정 통과, 사람의 식별률·난이도 결과는 없습니다. 테스트 fixture와 시뮬레이션을 실제 참가자 기록으로 보고하지 않습니다.

## 설치와 연결

공식 bHaptics Haptic Plugin의 `Assets/Bhaptics/SDK2`와 macOS 네이티브 라이브러리를 로컬 설치했습니다. `GCCD_BHAPTICS_SDK2`가 Standalone에서 활성화되었습니다. Enable 메뉴는 저장소의 `.cs.txt` 어댑터 템플릿을 로컬 SDK 안에 설치합니다. SDK가 없는 새 checkout의 시뮬레이션 코드는 이 템플릿을 컴파일하지 않습니다. 같은 사용자의 기존 설정을 로컬에서 재사용했으며 비밀 값과 라이선스 SDK는 Git에 포함하지 않습니다. 다른 PC는 My Assets에서 Haptic Plugin을 임포트하고 Developer Window에서 설정한 뒤 `GCCD > Silent Study > Enable Installed SDK2`를 실행합니다. [공식 Unity 설치 안내](https://docs.bhaptics.com/sdk/unity/guide)를 따릅니다.

Player를 실행하고 **X40 한 대**를 연결·페어링합니다. 연구자 화면에서 `Use real bHaptics output`과 `Check SDK / Player / X40 connection`을 누릅니다. 이름에 X40가 없는 경우 Inspector의 모델 확인을 사용하기 전에 Player에서 모델을 확인합니다. 장치 주소는 원문 대신 SHA256 해시만 기록합니다. SDK 초기화/전달 승인과 신체에서 실제 진동을 느꼈다는 응답은 별개입니다.

## 40채널 위치·편안함 확인

익명 ID와 시드를 설정하고 `40-channel position and comfort calibration`을 실행합니다. 무작위 순서로 각 채널에 **35/100, 150ms** 단일 펄스를 한 번 전송합니다. 두 패널의 숫자는 **착용자 기준 왼쪽 → 오른쪽, 위 → 아래**이며 전면 0–19, 후면 20–39입니다. 외부에서 바라본 앞면의 좌우와 혼동하지 않습니다.

착용자가 느낀 위치를 선택한 뒤 `felt and comfortable`를 확인합니다. 첫 위치 선택은 잠기고, 8초 동안 확인하지 않으면 무응답으로 저장됩니다. 불편하면 전용 중지 버튼을 사용합니다. 40/40 정확한 위치·편안함·전달 승인과 전체 완료가 모두 필요합니다. 오답, 누락, 중단, 장치 변경, 설정 변경, 시뮬레이션은 통과 증명으로 인정하지 않습니다. 이 단계는 위치·편안함 확인이며 센서로 물리 지연이나 지각 강도 동등성을 측정하지는 않습니다.

## 교육과 블라인드 식별

레이블이 있는 TRAINING 버튼으로 유형과 방향을 익힙니다. 교육은 증명 데이터에 포함되지 않습니다. 이후 C의 유형 시험, D의 유형+방향 시험을 실행합니다. 각각 유형 3 × 방향 4 × 반복 4 = **48회**이며 별도 고정 시드를 사용합니다. C는 위치 정보 없이 동일 중립 위치, D는 현재 시점 기준 4구역에 출력합니다. 같은 시간 패턴과 노출 상한을 사용합니다.

시험 중에는 실제 유형/방향·정답 여부·누적 점수를 표시하지 않습니다. 사건 후 4초 내 첫 유형·방향 선택과 편안함 확인을 기록합니다. 유형·방향 선택 시각과 최종 확인 시각을 따로 저장합니다. 무응답도 전체 시행 분모에 포함하며, 혼동행렬에는 결측 열이 있습니다. 각 유형, D의 각 방향 정확도 **80% 이상**, 전체 48회 유효 물리 출력·편안함 확인을 통과 기준으로 선언했습니다. 참가자·장치·패턴이 달라지면 기존 식별 통과 기록을 재사용하지 않습니다. 이 기준은 파일럿 운영 기준이며 보편적인 검증 기준이라고 주장하지 않습니다.

## 난이도 파일럿

시나리오 easy/base/hard와 A–D 조건을 선택하고 `Start difficulty pilot`을 누릅니다. 난이도 차이는 추격 속도 1.6/2.3/2.8m/s와 시행 제한 24/20/17초입니다. 노출·반응·추격 창·사건 균형·환경은 기본 시나리오와 같습니다. A–D는 같은 난이도/시드를 사용하며 Williams 순서를 확인합니다. Easy/Hard 설정을 바꾸었다면 해당 설정을 새 파일럿 블록으로 확인합니다.

전체 유효 15회 이상을 완료해야 판정합니다. 목표 성공률 ≤20%는 바닥 가능성, ≥90%는 천장 가능성, 그 사이는 잠정 사용 범위로 표시합니다. 반응 누락·회피·탐지·중단·프레임 간격도 함께 확인합니다. 한 사람의 한 조건만으로 최종 난이도를 확정하지 않고 여러 참가자·조건 결과를 비교한 뒤 본 실험 설정을 고정합니다. 프로그램이 본 실험 도중 난이도를 자동 변경하지 않습니다.

## 저장·복구·중단

교정·식별: `Application.persistentDataPath/SilentPilots/<SessionID>/`의 configuration.json, trials.csv, journal.jsonl, evidence.json, summary.json. 난이도: `SilentStudy/<SessionID>/`에 기존 결과와 difficulty-review.json. macOS 기본 경로는 `~/Library/Application Support/GCCD/GCCD Threat Lab/`입니다. 각 응답을 저널에 즉시 저장하고 최종 행을 한 번만 저장합니다.

Esc, 불편함, 포커스 상실, 일시정지, 종료, 연결/장치 변경, 설정 변경, 출력 실패는 중단·저장하며 자체 출력 요청을 중지합니다. 중단 시행은 Valid=false입니다. 앱 재실행 시 저장된 전체 증명 기록에서 통과를 다시 계산합니다. Purpose가 HardwarePilot/DifficultyPilot인 파일은 `Tools/silent_results.py analyze`의 본 실험 집계에서 제외합니다. 복구는 같은 도구의 recover로 원본을 보존한 새 CSV를 생성합니다.

## 장비가 확보되면 남은 확인

실제 X40에서 전후·좌우·상하 40채널 체감, 세 시간 패턴 구별, 방향 체감, 연결 중지/재연결, 편안한 강도를 확인해야 합니다. 물리 지연과 동일 지각 강도는 추가 관찰·계측이 필요합니다. 실제 사람의 파일럿을 완료한 후 수치와 제외 사유를 보고서에 넣습니다.
